## 为什么之前看起来“功能不可用”

1. 菜单状态原来直接打印 JSON，用户难以判断功能是否执行；现在改为中文状态面板，JSON 只保留给脚本化状态查询。
2. `frps` 客户端连接菜单原来展示原始 JSON；现在解析 v2 envelope，显示客户端、代理、在线状态和流量摘要。
3. 部分菜单只完成了入口，缺少完整非交互路由；当前补齐了 profile 删除、mapping 子命令、安装器参数和安全卸载。
4. 安装器早期静默忽略参数，导致 `--version`、`--non-interactive` 等看似可用但没有效果；现在支持已验证版本白名单、拒绝未实现自定义路径和明确的 non-interactive/no-start/no-autostart 行为。
5. Windows 和 OpenRC 代码在 macOS 上无法实机验证；代码存在不等于平台验收通过，文档现明确区分静态验证与真机验证。

## 仍然需要补齐的后续范围

- Windows 实机安装、WinSW SCM、ACL、PowerShell 5.1/7 中文编码；
- Alpine/OpenRC 实机安装；
- HTTP/HTTPS/UDP 跨机器真实业务数据；

审计结论：首期 Debian/systemd、macOS 原生集成和核心配置管理已具备可测试实现；Windows/OpenRC/跨版本升级仍是明确边界，不能把菜单入口当成已经验收的功能。
