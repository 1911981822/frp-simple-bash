# v0.1.1-menu.1 菜单显示修复

本版本修复终端 `frps`/`frpc` 菜单的状态展示：

- 数字菜单使用中文状态面板，显示运行状态、frp 版本和配置路径。
- frps 显示业务监听地址与端口、Dashboard 地址、仅本机访问提示，不回显 token 或管理密码。
- frpc 显示当前服务端别名及地址、连接状态、映射数量和待生效状态。
- 选择编号 1 时只刷新一次面板，不再先输出一份 JSON 又重复输出下一轮状态。
- frps 菜单不依赖 frpc 当前 profile，损坏或缺失的客户端 profile 不再影响服务端菜单标题。
- `frps status --json`、`frpc status --json` 保留 JSON，用于脚本调用；兼容现有行为，`status` 默认也仍输出 JSON。

本次不修改 frp 原生版本，不覆盖用户配置、token、映射，不需要重启运行中的 frps/frpc 服务。

新增三项回归测试验证菜单刷新次数、中文字段、秘密不展示、JSON 保留及服务端/客户端状态隔离。本地完整测试共 38 项通过，含官方原生 frp 0.72.0 集成测试。

固定发布目录：`/frp-simple-bash/releases/v0.1.1-menu.1/`。旧管理器版本目录继续保留。顶层安装入口更新到此版本；当前已安装实例可仅更新共享菜单核心，避免重新安装或中断连接。
