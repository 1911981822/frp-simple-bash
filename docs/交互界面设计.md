# 终端交互界面设计与使用说明

## 交互层级

`frps`/`frpc` 采用宝塔终端风格：

```text
清屏
  ↓
显示当前状态
  ↓
显示编号菜单
  ↓
输入编号
  ↓
显示带标签的执行结果
  ↓
按回车返回当前/上一级菜单
```

### 结果标签

- `[成功]`：操作已经完成并通过服务状态或配置检查；
- `[提示]`：操作有效，但需要后续重启、配置或用户确认；
- `[失败]`：操作未完成，后面会有原因和建议；
- `[菜单]`：当前层级菜单；
- `[状态]`：当前服务、连接和配置状态。

## 返回规则

- 所有子菜单使用 `0. 返回上一级`；
- 主菜单使用 `0. 返回/退出`；
- 端口映射子菜单的 `0` 返回 frpc 主菜单；
- 配置表单中取消不会写入配置；
- 交互终端在操作结果后按回车再回到菜单；非 TTY 测试输入不会额外等待回车。

  1. 查看服务信息（状态、版本、路径）

```

```

## 脚本调用

交互界面不会影响 JSON 自动化接口：

```bash
frps status --json
frpc status --json
frpc profile list
frpc mapping list
```

JSON 用于脚本和监控，不会在默认数字菜单中混入原始 JSON。具体覆盖和平台限制见[需求实现覆盖审计](<需求实现覆盖审计.md>)。
