## 实现决策

1. Bash/PowerShell 负责安装和命令入口，Python 负责配置解析、菜单业务和事务。Python 3.11+ 使用 tomllib；Linux Python 3.9/3.10 可安装发行版 tomli。此决策用于避免用 sed 修改 TOML 导致秘密转义、数组和字段层级损坏。
2. `/usr/local/bin/frps`、`frpc` 是菜单入口；系统服务直接调用 `/opt/frp-simple-bash/native/frps`、`frpc`。二者必须分开，不能让 service 启动交互菜单。
3. Windows 原生 frp 不直接注册为 SCM 服务。使用 WinSW v2.12.0 固定官方资产，并校验登记的 SHA256；服务名为 `frp-simple-bash-frps`、`frp-simple-bash-frpc`。
4. profile 内有不可变随机 ID、可变唯一别名、独立连接参数、秘密和映射。界面编号只对当前选择列表有效。
5. 停用代理通过不生成该代理实现。没有采用 `start=[]`，因为空全局白名单并不表示停用全部代理。
6. TOML 生成使用点号字段和安全字符串编码；HTTP/HTTPS 的域名生成 `customDomains`，与 TCP/UDP 的 `remotePort` 区分。
7. 启用客户端本机 Admin API 绑定 127.0.0.1:7400，使用随机管理密码。Dashboard 与 frpc Admin 的端口和凭据独立。
8. 外部 includes/Store/高级配置不执行有损反向导入；提示冲突并保留原文件。支持基础连接参数、认证和映射的导入。
9. 普通保存采用独占锁和多文件异常回滚，包括 profile、映射、运行 TOML、state、index。断电级事务与异常锁自动恢复未验收。
10. 首期升级菜单仅重装固定 0.72.0；跨版本升级需要扩展版本清单与兼容迁移。

## 原生 API 实测修正

官方 macOS ARM64 资产：

- https://api.github.com/repos/fatedier/frp/releases/assets/710291519
- SHA256：`6e8576c5b6b9914a86850f6ff4fb81c5a09e706f91f70f64d5f398558bdc9db8`
- `frps --version`、`frpc --version` 均输出 `0.72.0`。

真实运行发现，frps v2 API 不直接返回列表，而有外层 envelope：

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "total": 1,
    "page": 1,
    "pageSize": 50,
    "items": []
  }
}
```

源码证据：上游 `pkg/util/http/handler.go` 中 `V2Response`、`MakeHTTPHandlerFuncV2`。先前技术报告的列表示例描述的是 `data` 内部结构，缺少 envelope。共享 API 客户端现已按 `code == 200` 检查并提取 `data`；frpc `/api/status` 保持原始结构。

## 已执行的测试

测试命令：

```bash
FRP_NATIVE_DIR="$PWD/.test-native/frp_0.72.0_darwin_arm64" python3 -m unittest discover -s tests -v
```

执行环境：macOS ARM64、Python 3.15、本地官方 frp 0.72.0 发布包。

已通过 22 项测试（19 项行为测试 + 3 项原生集成测试），范围：

- 中文服务端别名与 IPv6 展示；
- 重复名称、路径穿越和非法菜单输入；
- token 特殊字符的 TOML 往返与配置文件权限；
- 多 profile 映射隔离与跨 profile 写入拒绝；
- 映射停用不生成、删除清空、重复端口拒绝；
- 校验失败和后置写入故障时恢复模型/运行配置/state/index；
- 取消配置编辑不写入；
- 外部基础配置导入、跨 profile 导入拒绝、高级字段不丢失；
- frps 恢复管理器规范配置；
- 30 秒超时逻辑和“进程存在不等于连接成功”；
- 原生 frps/frpc 配置 verify；
- 本地真实 token/TLS 连接、客户端上线、IPv6 `::1` 登录；
- TCP/UDP/HTTP/HTTPS 四种代理注册及 running 状态；
- 真实 TCP 隧道回声数据往返；
- frps v2 clients/proxies 分页结构与 frpc Admin status；
- 无 Basic Auth 凭据请求返回 HTTP 401。

Linux Bash 入口、安装器、卸载器完成语法检查；PowerShell 文件完成静态检查。GitHub Actions 已配置 Ubuntu/Windows 测试与 PowerShell AST 解析，但尚未推送执行。
