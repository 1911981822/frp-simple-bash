## 镜像安装测试的精确范围

安装测试实际执行下载得到的 `bash -c` 入口，不使用 `FRP_ARCHIVE_PATH`。为测试国内源站且避免 Cloudflare 路由影响，仅该测试进程通过临时 CURL_HOME 的 resolve 配置把下载域名连至源站回环地址，仍以域名执行正常 HTTPS 证书校验。没有修改系统 hosts/DNS。源码包、摘要和原生包实际经过 HTTPS 下载并核验。

公网域名下载另行验证。此证据不等于 Windows 实机、OpenRC 或所有公网网络路径已验收。

## Cloudflare 限制

域名部署时为橙云代理，因此当前不能声称客户端会直连国内服务器。建议将下载域名设为 DNS only（灰云），A 记录指向源站；若保留代理则使用 Full (strict)。部署发现 Flexible 回源造成跳转循环，静态站点已兼容代理 HTTPS 头；旧 URL 重定向缓存通过安装器资源版本查询参数规避。
