# 深度功能补齐记录

本文件记录按需求、概要设计和详细设计补齐的深层功能，避免再次出现“只有菜单入口、没有实际能力”的情况。

## 本次补齐的功能

### 1. frps 配置增量编辑

原实现只有一次性重写向导，无法查看或局部修改已有配置。现改为独立配置子菜单：

```text
[菜单] frps 服务端配置
  1. 查看当前配置（脱敏）
  2. 修改业务监听地址/端口
  3. 修改 token
  4. 修改 Dashboard/API
  5. 修改 HTTP/HTTPS vhost 端口
  6. 修改 KCP/QUIC/TCPMUX 端口
  7. 校验配置并检测端口冲突
  8. 查看防火墙放行提示
  9. 备份与恢复配置
  0. 返回上一级
```

每次修改都会：字段校验 → 原生 `verify` → 备份 → 原子写入 → 可选重启 → 状态反馈。

### 2. 配置校验与端口冲突检测

- `validate_frps_config` 校验端口范围、监听地址、token 最小长度、Dashboard 必须同时设置用户名和密码；
- 通过 `ss` 检测本机端口占用，避免重复监听；
- 校验失败不会覆盖现有配置。

### 3. 防火墙只检测、不修改

按需求要求，仅检测 `ufw`、`firewalld` 和 Windows 防火墙状态，给出可操作提示，绝不自动修改规则。

### 4. 备份与恢复

- 备份按相对路径保存，包含 `manifest.json` 清单和变更原因；
- 恢复前校验路径不越界、文件存在、非符号链接；
- 恢复前自动再备份当前状态；
- 提供非交互命令：

```bash
frps backups
frps restore <备份目录名>
```

### 5. 连接诊断

新增 `diagnostics` 与 `diagnostics_report`：

- 服务状态；
- 配置语法校验；
- 端口可达性；
- Dashboard 认证；
- 防火墙提示；
- frpc 当前服务端、连接状态、待生效修改、端口占用提醒。

菜单入口：

- frps：`连接诊断`；
- frpc：`查看日志与连接诊断`。

非交互：

```bash
frps diagnose
frpc diagnose
```

输出 JSON，便于脚本和监控采集。

### 6. 配置查看脱敏

`profile_summary` 和 `frps config show` 不再输出原始 TOML，只显示是否设置 token、是否启用 TLS、Dashboard 端口等；JSON 输出中的敏感字段替换为 `******`。

### 7. 映射列表可读化

端口映射列表改为表格显示：名称、类型、本地地址、远端端口或域名、启用状态，不再输出原始 JSON。

### 8. TOML 序列化修复

原序列化器不支持嵌套表，导致 `auth`、`webServer` 等 frps 配置无法生成。现已支持嵌套表和表数组，并加入往返测试。

## 非交互命令补充

```bash
frps config show
frps config validate
frps diagnose
frps backups
frps restore <name>
```


### 9. frpc profile 深度编辑

profile 配置菜单新增：

- 传输协议：tcp/kcp/quic/websocket/wss；
- 传输加密与压缩开关；
- 日志级别 trace/debug/info/warn/error；
- 日志保留天数 1-365。

这些字段会写入生成的 `frpc.toml`，并支持从手工修改的配置反向导入。

### 10. 日志管理

新增日志子菜单：

- 列出当前日志与轮转归档；
- 查看最近 50 行 / 200 行；
- 清理轮转归档但保留当前日志；
- 显示日志目录与轮转策略。

非交互命令：

```bash
frps logs 200
frpc logs 50
frps logs-clean
```

### 11. 升级校验与回滚

- 升级前读取实际原生版本并显示；
- 只接受已核验版本，其他版本明确拒绝；
- 升级前备份配置；
- 升级脚本失败时自动恢复配置并重启服务；
- 升级后校验服务状态。

`version` 命令现在输出管理器版本、实际 frp 版本和支持版本列表。
